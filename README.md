# CodingCush Games

Source of [games.codingcush.com](https://games.codingcush.com): free browser games made with Godot.

| Path | What it is |
|---|---|
| `index.html`, `vyomastra/index.html`, `404.html`, `sitemap.xml`, `robots.txt`, `llms.txt` | Static pages, generated by `_src/build_site.py` |
| `vyomastra/play/` | Web build of Vyomastra (Godot 4 export) |
| `api/` | PHP + MySQL API: accounts, cloud saves, leaderboards |
| `assets/` | Page images |

## Deploy

Hostinger's Git deployment pulls the `main` branch into `public_html/games`, so a push to `main` goes live.

## Database

Nothing to set up: with no `api/config.php` the API keeps accounts, saves and scores in one SQLite file, stored outside the web folder (`games-data/games.sqlite` beside `public_html`). To move to MySQL later, run `api/schema.sql` in phpMyAdmin and create `api/config.php` from `api/config.sample.php`; that file is ignored by git and blocked from the web.

## Editing pages or adding a game

Edit `_src/build_site.py`, then run `python3 _src/build_site.py`. It rewrites the pages in place.
